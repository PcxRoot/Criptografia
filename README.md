# 🔐 Cryptography Lab & Learning Journey

Bienvenido/a a mi repositorio de aprendizaje en **criptografía aplicada a la ciberseguridad**. Aquí documento conceptos teóricos, implementaciones prácticas de algoritmos, análisis de vulnerabilidades criptográficas y soluciones a retos concretos de CTF.

El propósito de este espacio es construir una base matemática y técnica sólida, entendiendo tanto el funcionamiento de los sistemas criptográficos como los vectores de ataque más comunes en escenarios reales y de hacking ético.
